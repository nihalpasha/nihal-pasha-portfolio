# Nihal Pasha M. — Personal Portfolio

Responsive white-and-blue portfolio using HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` in a browser, or use Live Server.

## Add your profile photo
Upload a professional photo in this chat so it can be prepared for the site. The current page uses `assets/profile-photo-placeholder.svg`. To use your own image, save it in `assets` as `profile-photo.jpg` and change the image `src` in `index.html` to `assets/profile-photo.jpg`. A square photo works best.

## Connect your resume PDF
Copy your resume PDF into the same folder as `index.html` and name it exactly `resume.pdf`. The Download Resume button already links to this file. If you choose a different filename, update the button's `href` in `index.html`.

## Finish before publishing
- Replace `YOUR-EMAIL@example.com` in both `index.html` and `script.js`.
- Add your actual LinkedIn and GitHub URLs.
- Replace sample project links with your real repositories and verify project details.
- Check that the skills and experience accurately reflect your background.

The contact form opens the visitor's email app using `mailto:`; it does not send or store messages directly.
